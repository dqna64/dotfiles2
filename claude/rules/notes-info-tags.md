# Information tags in Gordon's hand-written notes

Gordon likes to use emoji tags to categories certain pieces of information. Use them where relevant; stay surgical and match the surrounding lines.

| Emoji | Name | Meaning |
|---|---|---|
| 🌼 | Blossom | Important information |
| 🍉 | Watermelon | Fun or interesting information |
| 💥 | Explosion | Milestone or notable achievement |
| ♻️ | Recycle | Information worth revisiting |
| 🔥 | Fire | Interesting, to share, to start a conversation about |
| 💎 | Gem stone | Useful reference material |
| 🌀 | Cyclone | The title of a discrete task: something that can eventually be completed. Its nested blocks may feature more specific info, status items and action items, as well as other sub-tasks, that constitute this task. |

## Placement
- Put the emoji at the start of the list item.
- If the item calls for action, put it after the markdown checkbox.

```
- [ ] 🌼 [company strategy H1 2027](https://example.com)
- [ ] 🍉 [season opener easter egg](https://example.com)
- 💥 released feature X to 5% public
- 💎 [feature Y documentation](https://example.com)
```
